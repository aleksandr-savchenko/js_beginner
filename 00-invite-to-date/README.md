## ✅ Schritt 1: Prüfen, ob Node.js installiert ist

Öffne dein Terminal und gib ein:

```bash
node -v
```

Wenn Node.js **nicht installiert** ist, kannst du es hier herunterladen und entsprechend deiner Plattform installieren:  
👉 [https://nodejs.org/en/download](https://nodejs.org/en/download)
